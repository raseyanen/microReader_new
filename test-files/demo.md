## Дискриминант
Квадратное уравнение ax^2 + bx + c = 0 имеет вещественные корни, если D >= 0.

Если D = 0, корень один.
tex: D = b^2 - 4ac
tex: x_{1,2} = \frac{-b \pm \sqrt{D}}{2a}
