# microReader ESP32-C3 — миниатюрная читалка / шпаргалка

Карманное устройство на **ESP32-C3 Super Mini** с OLED-дисплеем 128×64 (SSD1306),
три кнопки, питание от аккумулятора через TP4056. Поддерживает загрузку файлов
по Wi-Fi и отображение:

| Формат | Что показывает |
|---|---|
| **.txt** | Текст в кодировке UTF-8 (до 8 строк × 21 символа на экран) |
| **.jpg** | Монохромные изображения (декодирует TJpg_Decoder, большие картинки листаются по частям) |
| **.tex** | Математические формулы в TeX-синтаксисе — собственный рендер, **одна формула = одна страница** |
| **.itxt / .h** | Текст с встроенным массивом картинки (см. «Подготовка изображений») |

Также в прошивке: веб-загрузка файлов, игры (динозавр, тетрис, змейка),
калькулятор, сервисный режим и **глубокий сон**.

## Обновление для ESP32-C3 Super Mini (эта версия)
- Порт прошивки v1.2 с ESP8266 (ESP12E) на **ESP32-C3 Super Mini**
- **Новый рендер формул `.tex`**: интегралы, суммы, пределы, дроби, корни, акценты и т.д. (полный синтаксис ниже)
- Одна формула — одна страница, названия формул через `\title{...}` или `## Название`, счётчик страниц
- Листание формул кнопками вверх/вниз
- **Глубокий сон** из меню игр (`ГЛУБОКИЙ СОН`), пробуждение по любой кнопке (EXT1 wakeup, GPIO0–3 — RTCIO)
- Напряжение батареи измеряется на GPIO1 (ADC1_CH1) через делитель 100к/100к
- Загрузка скетча по USB (USB CDC On Boot), OTA через веб-интерфейс

## Распиновка (ESP32-C3 Super Mini)
| Функция | Пин |
|---|---|
| Кнопка ВВЕРХ | GPIO3 |
| Кнопка ОК | GPIO2 |
| Кнопка ВНИЗ | GPIO1 (совмещена с ADC измерения батареи) |
| SDA / SCL дисплея | GPIO8 / GPIO9 (в скетче; на части плат выводят на GPIO6/GPIO7 — поменяй defines при необходимости) |
| Светодиод | LED_BUILTIN (GPIO8 на большинстве плат) |

Номера пинов настраиваются `#define`-ами в начале `a-microReader-esp32c3.ino`.

## Компиляция и прошивка
- Скетч: **firmware/a-microReader-esp32c3**
- Ядро: [esp32](https://espressif.github.io/arduino-esp32/package_esp32_index.json), версии **2.0.x / 3.x**
- Настройки Arduino IDE:
  - Board: **ESP32C3 Dev Module**
  - USB CDC On Boot: **Enabled**
  - Flash Size: **4MB**, Partition Scheme: **Minimal SPIFFS (1.9MB APP with OTA/1.9MB SPIFFS)**
  - Erase All Flash Before Sketch Upload: **Enabled** (при первой прошивке)
- Библиотеки из папки **libraries** копируются в папку библиотек IDE **с заменой**
- Прошивка по воздуху (OTA) доступна из веб-интерфейса; готовый бинарник — `firmware/BIN/a-microReader-esp32c3.ino.bin`

## Режимы работы
### Главное меню
Выбор файла для чтения. Файлы загружаются через Wi-Fi-меню.

### Режим «Wi-Fi Меню»
- Активируется **удержанием** средней кнопки в главном меню
- Позволяет конфигурировать устройство, обновлять прошивку (OTA), загружать и удалять файлы
- **Режим AP** — устройство создаёт сеть (имя/пароль/IP выводятся на экран); по умолчанию точка доступа `Reader AP` / пароль `00000000`
- **Режим STA** — подключение к домашней сети из веб-морды (с автоподключением)
- Веб-интерфейс — открыть указанный IP в браузере устройства, находящегося в той же сети
- Кнопки вверх/вниз в сетевом режиме — регулировка яркости дисплея
- Выход — средняя кнопка или таймаут 5 минут

### Игровой режим и утилиты
- Активируется **удержанием** кнопки «вверх» в главном меню
- Игры: динозавр, тетрис, змейка
- Утилита **ГЛУБОКИЙ СОН**: отключает устройство в deep sleep. Пробуждение —
  нажать **любую** кнопку (EXT1 wakeup по низкому уровню на GPIO0–3, все они RTCIO).
  После пробуждения устройство перезагружается, как при обычном включении
- Выход в главное меню — кнопка «вверх»

### Сервисный режим
- Включение устройства с **зажатой** кнопкой «вверх»
- Сброс настроек и форматирование файловой системы

### Калькулятор
- Вверх/вниз — менять число; удержание ОК — следующее число; двойной клик ОК — посчитать; тройной клик ОК — выход

## Поддерживаемые файлы
- Имена файлов — **до 12 символов**, кириллица или латиница, расширения **.txt / .jpg / .tex / .itxt / .h**; файлы с длинным именем или другим расширением не отображаются
- Если рядом с числом файлов стоит скобка, например `10[14]`, — часть файлов не прошла проверку
- Образцы лежат в папке **test-files** (`файл.txt`, `formulas.tex`, `*.jpg`)

# Синтаксис формул `.tex`

Формат рассчитан на экран 128×64: **одна формула = одна страница**.

## Структура файла
```tex
% строки, начинающиеся с % или // — комментарии (не отображаются)

\title{Название}          <- название формулы (выводится сверху страницы)
e^{i\pi} + 1 = 0         <- сама формула (можно писать до 5 строк подряд)

## Integral               <- альтернативный способ задать название
\int_0^{\infty}{e^{-x^2} dx} = \frac{\sqrt{\pi}}{2}
```
- Новая формула начинается либо с `\title{...}` / `## ...`, либо с непустой строки после предыдущей формулы
- До **5 строк** текста склеиваются в одну формулу (блок); всего до 24 названных страниц
- Листание страниц — кнопки вверх/вниз, название и счётчик страниц показываются на экране

## Базовые конструкции
| Синтаксис | Пример | Результат |
|---|---|---|
| `^{...}`, `_{...}` | `x^2`, `a_{ij}`, `x^{n+1}` | степени и индексы |
| `\frac{a}{b}`, `\dfrac{a}{b}` | `\frac{dy}{dx}` | дробь |
| `\binom{n}{k}` | `\binom{n}{k}` | биномиальный коэффициент |
| `\sqrt{x}`, `\sqrt[n]{x}` | `\sqrt[3]{2}` | корень (квадратный / n-й степени) |
| `{...}` | `{a+b}^2` | группировка |

## Крупные операторы (с пределами)
| Команда | Описание |
|---|---|
| `\int_a^b{...}` | определённый интеграл |
| `\iint`, `\iiint` | двойной / тройной интеграл |
| `\oint_C{...}` | контурный интеграл |
| `\sum_{a}^{b}{...}` | сумма |
| `\prod_{i=1}^{n}{...}` | произведение |
| `\coprod` | копроизведение |
| `\bigcup`, `\bigcap` | объединение / пересечение семейств |
| `\lim_{x \to a}{...}`, `\limsup`, `\liminf` | пределы (подпись снизу) |
| `\underbrace{...}_{подпись}` | нижняя огибающая с подписью |
| `\overbrace{...}` | верхняя огибающая |

Пределы пишутся как `_{}^{}` после команды: `\sum_{n=1}^{\infty}{\frac{1}{n^2}}`.

## Дифференциалы
Дифференциал — обычная `d` плюс функция/переменная:
```tex
\frac{dy}{dx}                    производная
\frac{\partial u}{\partial t}    частная производная (\partial)
\int f(x)\,dx                    dx внутри интеграла
df = \frac{\partial f}{\partial x}dx + \frac{\partial f}{\partial y}dy
```
Команда `\,` (тонкий пробел) трактуется как обычный пробел.

## Текст и оформление
- `\text{...}`, `\mathrm{...}`, `\mathit{...}`, `\mbox{...}`, `\operatorname{...}` — текст внутри формулы
- `\textbf{...}`, `\mathbf{...}`, `\boldsymbol{...}` — жирное начертание
- `\left( \right)`, `\bigl \Bigl \biggr \Bigr` — скобки (рендерятся как обычные)
- `\begin{equation} ... \end{equation}`, `\section`, `\label`, `\nonumber` — игнорируются (можно вставлять выдержки из LaTeX-документов)
- `$ ... $` — маркеры формулы, игнорируются
- Неизвестные команды печатаются как текст без обратного слэша

## Подготовка изображений (.itxt/.h)
- Дисплей монохромный 128×64; картинки хранятся текстом (массив)
- Утилита **image-processor/imageProcessor.exe** (нужна Java): OPEN IMAGE → подобрать размер и порог → SAVE → получится файл `.h`
- Переименовать (≤12 символов) и загрузить на устройство через веб-интерфейс

## Решение проблем
- Файл не виден в меню — слишком длинное имя или неподдерживаемое расширение
- «Мигает светодиод» — ошибка инициализации дисплея: проверить пайку I2C и остатки флюса
- Формула не влезает в страницу — разбейте её на несколько формул (строк между `\title{}`)
